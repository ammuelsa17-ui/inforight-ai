## 2. Invariant Rules for Translations
1. **Never translate official acronyms into invented terms**: `RTI`, `e-Jagriti`, `NCH 1915`, `SAMADHAN 2.0`, `PM-KISAN`, `MGNREGA`, `PIO`, `CPIO`, `SPIO` must remain clearly recognizable in English or bilingual bracketed text.
2. **Statutory section citations**: Preserve exact statutory numbers like `Section 6(3)`, `Section 7(1)`, `Section 19(1)` across all language versions.
3. **No hype words**: Avoid "instant justice", "guaranteed solution", "100% win", "congratulations". Use objective phrasing: "Based on verified criteria", "Next recommended statutory step".
