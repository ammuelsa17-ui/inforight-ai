## 2. Terminology Consistency Rules Applied
1. **Acronym Recognition**: `RTI`, `e-Jagriti`, `NCH 1915`, `SAMADHAN 2.0`, `PM-KISAN`, `PIO`, `CPIO` preserved across all 23 language dictionaries.
2. **Distinct Voice vs UI Language Labels**: Differentiated interface language selection (`Interface Language`) from voice input language (`Voice Language`).
3. **Objective Status Labels**: Standardized badges to `Eligible`, `Not Eligible`, and `More Information Needed` (no over-promising or hype words).
